# PORTFOLIO

This is my current person website. It is hosted via "Pages" in Cloudflare. Make a change here and poof! It's deployed!

## Where the content lives
- `source/blog/*.md`: blog posts (files starting with `_` are skipped).
- `source/data/experience.json`: the experience timeline. `end: null` means current; the axis grows with the year.
- `source/data/projects.json`: the "in the hopper" side project cards.
- `source/data/skills.json`: professional skills on the experience page.
- Letterboxd: movies on odds & ends come from the RSS feed at build time (`letterboxd.py`).
